# Screenshots Directory

Save your 4 application screenshots into this folder with these exact filenames:

1. `dashboard.png` — Screenshot of the Dashboard (http://localhost:5173/)
2. `applications.png` — Screenshot of Applications page (http://localhost:5173/applications)
3. `companies.png` — Screenshot of Companies page (http://localhost:5173/companies)
4. `predictions.png` — Screenshot of ML Predictions page (http://localhost:5173/predictions)

Once saved, they will display automatically in the main project `README.md` on GitHub!
